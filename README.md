## 先说为什么是东京 CN2 GIA

搬瓦工东京机房走的是电信 CN2 GIA 专线，回程三网都是 CN2 GIA——电信、联通、移动全部绕回 CN2 GIA 线路进国内。这个组合在中文 VPS 圈子里基本算「天花板配置」了。

电信 CN2 GIA 是中国电信四种 IP transit 方案里最贵的那档，单 Gbps 的 transit 成本能飙到上百美元每兆，带宽容量还特别有限。搬瓦工能把它接到日本东京，而且给到 1.2Gbps 的端口带宽，本身这件事就不便宜——这也是为什么东京套餐的价格明显比美国机房高一截的原因。

但贵有贵的道理。常规 IP transit 晚高峰丢包率能到 30% 以上，开会卡成 PPT、网页转圈、游戏掉线，都是这种网络的真实写照。CN2 GIA 解决的就是这个问题，丢包少、延迟稳、晚高峰照样能用。
